# ProjetosEDD2

Este repositório reúne uma série de projetos desenvolvidos com foco na prática de programação, organização de código e aplicação de conceitos estudados em aula. Cada pasta representa uma solução individual para um problema específico, com objetivo de exercitar lógica, estruturas de dados e desenvolvimento de sistemas.

## Projetos incluídos

### SistemaAgenda
Sistema de agenda para gerenciamento de compromissos, contatos e organização pessoal. O objetivo principal é permitir o cadastro, consulta e manutenção de informações de forma simples e funcional.

### SistemaAgendaWinForms
Versão da agenda desenvolvida com Windows Forms, focada em uma interface desktop mais visual e interativa. Esse projeto demonstra a aplicação dos mesmos conceitos em uma abordagem com GUI para usuários Windows.

### SistemaBiblioteca
Sistema de biblioteca para controlar livros, usuários e empréstimos. Ele visa facilitar a gestão de acervo, registros de alunos ou clientes e o controle de devoluções e disponibilidade dos materiais.

### SistemaRestaurante
Sistema para gerenciamento de um restaurante, com foco em organização de pedidos, mesas, cardápio e atendimento. O projeto simula operações comuns de um ambiente gastronômico, como registro de vendas e controle de itens.

## Objetivo geral
Os projetos presentes neste repositório foram criados para aplicar conceitos de programação, modelagem de dados, desenvolvimento de interfaces e resolução de problemas reais de forma prática e didática.
