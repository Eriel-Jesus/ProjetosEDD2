# ProjetosEDD2

Este repositório reúne uma série de projetos desenvolvidos com foco na prática de programação, organização de código e aplicação de conceitos estudados em aula. Cada pasta representa uma solução diferente, com objetivos específicos e abordagens variadas em linguagem e estrutura.

## Projetos incluídos

### SistemaAgenda
Sistema de agenda para gerenciamento de compromissos, contatos e organização pessoal. O objetivo principal é permitir o cadastro, consulta e manutenção de informações de forma simples e eficiente.

### SistemaAgendaWinForms
Versão da agenda desenvolvida com Windows Forms, focada em uma interface desktop mais visual e interativa. Esse projeto demonstra a aplicação dos mesmos conceitos em uma abordagem com GUI para usuários de ambiente Windows.

### SistemaBiblioteca
Sistema de biblioteca para controlar livros, usuários e empréstimos. Ele visa facilitar a gestão de acervo, registros de alunos ou clientes e o controle de devoluções e disponibilidade dos materiais.

### SistemaRestaurante
Sistema para gerenciamento de um restaurante, com foco em organização de pedidos, mesas, cardápio e atendimento. O projeto simula operações comuns de um ambiente gastronômico, como registro de clientes, controle de mesas e organização do atendimento.

### ProjetoAtendimento
Sistema de atendimento com foco na organização e controle de demandas, contatos e processos de suporte. O projeto representa uma aplicação prática para registrar atendimentos, acompanhar solicitações e melhorar a gestão de comunicação e serviço.

## Objetivo geral
Os projetos presentes neste repositório foram criados para aplicar conceitos de programação, modelagem de dados, desenvolvimento de interfaces e resolução de problemas reais de forma prática e didática.
