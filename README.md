# ProjetosEDD2

Este repositório reúne uma coleção de projetos desenvolvidos ao longo da disciplina de Estruturas de Dados e Desenvolvimento de Software, com foco em prática de programação, organização de código e aplicação de conceitos estudados em aula. Cada pasta representa um projeto individual, com objetivos específicos, estrutura de classes e soluções para problemas reais e acadêmicos.

## Projetos incluídos

### SistemaAgenda
Sistema de agenda para gerenciamento de compromissos, contatos e organização pessoal. O objetivo principal é permitir o cadastro, consulta e manutenção de informações de forma simples e eficiente.

### SistemaAgendaWinForms
Versão da agenda desenvolvida com Windows Forms, focada em uma interface desktop visual e interativa. Esse projeto demonstra a aplicação dos mesmos conceitos em uma abordagem com GUI para usuários finais.

### SistemaBiblioteca
Sistema de biblioteca para controlar livros, usuários e empréstimos. Ele visa facilitar a gestão do acervo, o registro de alunos ou clientes e o controle de devoluções e disponibilidade dos materiais.

### SistemaRestaurante
Sistema para gerenciamento de um restaurante, com foco em organização de pedidos, mesas, cardápio e atendimento. O projeto simula operações comuns de um ambiente gastronômico, como registro de clientes, controle de mesas e processamento de pedidos.

### ProjetoAtendimento
Sistema de atendimento com foco na organização e controle de demandas, contatos e processos de suporte. O projeto representa uma aplicação prática para registrar atendimentos, acompanhar solicitações e manter registros de comunicação.

### Projeto Controle de Acessos
Sistema voltado ao controle de acesso, com abordagem em gestão de usuários, permissões e autenticação/autorizações. O projeto busca aplicar conceitos de organização de dados e regras de acesso em um ambiente de administração.

## Objetivo geral
Os projetos presentes neste repositório foram criados para aplicar conceitos de programação, modelagem de dados, desenvolvimento de interfaces, lógica de negócios e resolução de problemas reais de forma prática e didática.

## Competências trabalhadas
- Estruturação de algoritmos e lógica de programação
- Organização de classes e arquivos do projeto
- Manipulação de dados em memória
- Modelagem de sistemas simples e práticos
- Desenvolvimento de interfaces gráficas com Windows Forms
- Prática de CRUD e manutenção de registros
- Aplicação de conceitos de controle de acesso e regras de negócio

## Estrutura do repositório
Cada pasta representa um projeto independente, com sua respectiva lógica e implementação. A organização foi pensada para facilitar a visualização, manutenção e estudo individual de cada solução.

## Observação
Este repositório tem caráter acadêmico e de estudo, sendo útil como material de referência para revisão de conceitos, comparação de abordagens e desenvolvimento de novas soluções.
